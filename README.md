# Lakers Brasil — prévia de redesenho

Duas páginas estáticas para apresentação: uma cópia da home e de uma matéria do
[lakersbrasil.com](https://lakersbrasil.com) com uma proposta de redesenho
aplicada por CSS.

- `index.html` — home
- `materia.html` — página de matéria

**Não é o site no ar.** As páginas trazem `noindex` e existem só para
comparação visual. As fotos continuam sendo carregadas do servidor do próprio
site.

As fontes do tema original ficam em `fontes/` e os escudos dos times em
`logos/` porque o servidor de origem não libera esses arquivos para outro
domínio.
